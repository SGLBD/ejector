## 项目状态

目前提供 macOS 预览版，支持 macOS 13 及以上版本，包含 Apple 芯片和 Intel 两种架构。[下载预览版](https://github.com/SGLBD/ejector/releases)

## 为什么做「推出器」

我的 MacBook 内置空间不够，微信和 WPS 都依赖外接硬盘。每天上班插上两块盘就能开工，下班却要逐个退出软件，再一块块推出硬盘，确认都推出了才敢拔线。每天重复这一套，所以我做了「推出器」。

## 它能做什么

第一次使用时，选好要推出的硬盘，再为每块盘指定需要退出的应用。之后下班，只要在 Mac 菜单栏点一下 **「下班推出」**，推出器就会先正常退出关联应用，等它们完全退出后再推出硬盘，并逐块显示是否**可以拔出**。

- **两块盘一起推出，也可以只推出一块。** 临时只想带走一块盘，点「推出此盘」就行。
- **有文档没保存，就等你处理。** 比如 WPS 弹出保存提示，关联的硬盘会等 WPS 退出。另一块盘如果已经满足条件，可以先推出。
- **哪块盘卡住了，就单独处理哪块。** 如果硬盘还被文件、复制或同步任务占用，推出器会显示失败原因。解除占用后，可以单独重试这块盘。
